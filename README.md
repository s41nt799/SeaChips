# Sea Chips

**Хрустящие чипсы из морской капусты - статический сайт интернет-магазина**

Привет! Это личный проект - витрина для бренда полезных снеков из ламинарии. Я делал его, чтобы потренироваться в вёрстке, поработать с адаптивом и просто собрать красивую страницу для вымышленного (пока что) продукта. Никакого бэкенда, только фронтенд.

## Что внутри

- **Главная** (`index.html`) - лендинг с преимуществами, историей «производства» и отзывами.
- **Каталог** (`catalog.html`) - сетка вкусов.
- **Страница товара** (`product.html`) - карточка с описанием и кнопкой «в корзину».
- **Корзина** (`cart.html`, `cart-v2.html`) - два варианта оформления, второй посвежее.
- **Чекаут** (`checkout.html`, `checkout-v2.html`) - форма заказа (тоже в двух итерациях).
- **Админка** (`admin.html`) - простая страница для управления (заготовка).
- **Страница успешного заказа** (`order-success.html`).

Папки `css/`, `js/` и `images/`

## Стек

- Чистый **HTML5** и **CSS3**
- Немного **ванильного JavaScript** - в основном для интерактива на клиенте
- Никаких сборщиков и фреймворков - проект запускается двойным кликом по `index.html`
